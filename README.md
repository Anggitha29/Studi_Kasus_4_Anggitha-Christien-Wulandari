Penjelasan program :

Program ini digunakan untuk menyimpan dan mengelola data produk berupa pulpen. Data produk disimpan dalam Dictionary yang berisi nama, harga, dan stok. print() digunakan untuk menampilkan informasi ke layar, sedangkan input() digunakan untuk menerima pilihan atau data dari pengguna. Program menggunakan while True supaya menu dapat digunakan berulang kali. Pada menu pertama, pengguna dapat melihat data produk dengan mengakses key seperti produk["nama"], produk["harga"], dan produk["stok"]. Menu kedua digunakan untuk menambahkan kategori produk ke dalam Dictionary dengan produk["kategori"] = kategori. Menu ketiga digunakan untuk mengubah harga dengan produk["harga"] = harga_baru, sedangkan int() digunakan agar harga yang dimasukkan menjadi angka. Menu keempat digunakan untuk menghapus kategori dengan produk.pop("kategori"). if dan elif digunakan untuk menentukan menu yang dipilih oleh pengguna, sedangkan else digunakan jika pilihan tidak tersedia. Jika pengguna memilih menu kelima, break digunakan untuk menghentikan perulangan dan program akan selesai. Setelah program selesai, data produk terakhir ditampilkan untuk melihat perubahan yang telah dilakukan.
